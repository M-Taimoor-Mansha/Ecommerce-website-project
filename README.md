# 🛒 E-Commerce Website

A modern, responsive, and user-friendly E-Commerce website front-end built using pure **HTML5**, **CSS3**, and **JavaScript (ES6+)**. This project showcases an interactive shopping experience with product displays, dynamic cart management, and seamless UI responsiveness across devices.

---

## 🚀 Demo & Features

### Key Features
* **📱 Fully Responsive Design:** Fits perfectly on desktops, tablets, and mobile devices.
* **🛍️ Dynamic Product Showcase:** Interactive product listings with detailed views.
* **🛒 Interactive Shopping Cart:** Add to cart, remove items, and view price calculations dynamically.
* **🔍 Smooth Navigation:** Clean UI/UX with modern navigation bars and quick links.
* **🎨 Modern Styling:** Built using flexbox, CSS grid, and CSS custom properties for uniform aesthetics.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structural layout.
* **CSS3:** Custom styles, media queries, flexbox, and layout animations.
* **JavaScript (ES6+):** DOM manipulation, event handling, and local interactive logic.
